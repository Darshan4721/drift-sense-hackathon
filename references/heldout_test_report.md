# Held-out test report: seed base 900000

## Protocol

The bundled verifier checkpoint was trained on a separate 300-sample corpus generated with base seed `2026`, giving per-sample seeds `2027` through `2326`. The new test corpus used base seed `900000`, giving per-sample seeds `900001` through `900300`. The exact seed-overlap check returned **zero overlapping seeds**.

The test set contains 300 DRAM pairs generated by `generate_dataset.py`. Evaluation used the complete command-line pipeline:

```bash
python evaluate.py \
  --data-dir /tmp/drift-sense-heldout-900000 \
  --checkpoint checkpoints/best.pt \
  --tolerance 5 \
  --output-dir results_heldout_900000 \
  --method hybrid
```

The final measured inference configuration searched final-image scales `0.098`, `0.100`, and `0.102`, used rotations `-3`, `0`, and `+3` degrees, retained 12 local maxima per transformed template, and verified the top 16 classically ranked candidates with the bundled checkpoint. The classical reranker was reweighted toward intensity and local structure after inspecting the held-out failure cases.

## Failure diagnosis

All 17 failures were classified as `periodic_ambiguity`. No held-out failure was categorized as excessive noise, incorrect scale, rotation mismatch, blur, weak structural features, or boundary effect by the current failure-analysis rules. The largest measured errors were 486.2120 pixels for sample 246, 437.9343 pixels for sample 67, 434.7809 pixels for sample 145, and 403.4996 pixels for sample 30.

The failure images show that the synthetic DRAM layout contains repeated line/contact motifs. In the worst cases, a visually plausible repeated cell is selected at a distant location. The learned verifier also gives high scores to these repeated candidates, so the issue is not merely a missing candidate; it is a genuine ambiguity in the current appearance representation. The improvement changed the classical score weights from edge/periodicity-heavy scoring to intensity and structural agreement, reducing failures from 21/300 to 17/300 on the same held-out set and reducing mean error from 21.7394 to 18.1773 pixels. The full final run was then repeated after the change.

The residual weakness is therefore **periodic ambiguity**, not seed leakage, coordinate transposition, scale miscalculation, checkpoint loading, or runtime failure. The results should be treated as the actual measured performance of this synthetic benchmark, not as a guarantee for unseen proprietary Applied Materials imagery.
